# ps1-shooter

Space shooter untuk PlayStation 1, dibuat dengan PSn00bSDK.

**Kreator:** hidraneseiei21

## Fitur
- Hingga 4 pemain lokal (multitap)
- 19 tipe musuh + 2 boss (termasuk boss rahasia "Mad Cruiser")
- Sistem gacha untuk membuka skin pesawat
- Musik dan efek suara prosedural (SPU-ADPCM)
- Efek layar: screen shake, flash, fade transisi
- Latar tema warna yang berubah tiap 2 level

## Build
Lihat `.github/workflows/build.yml` untuk proses build otomatis via GitHub Actions,
atau build lokal dengan PSn00bSDK + CMake + Ninja.

## Kontrol
- **D-Pad**: gerak
- **X**: tembak
- **START**: join / mulai / pause
- **SELECT** (menu): buka gacha
- **SQUARE** (menu): pilih skin
